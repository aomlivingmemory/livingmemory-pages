Privacy policy

LivingMemory by AOM is developed by Alnur Meral.

Save a memory

Tap + in LivingMemory to save a link, note, photo, or video. In another app, use its Share menu and choose LivingMemory when available. Open LivingMemory afterward to finish importing a shared item. Safari’s LivingMemory extension also offers Save Link Only and Save Visible Area for supported webpages.

Find, edit, and delete

Use Library search and its filters to find saved items. Open a memory to view or edit its details. To delete one, use its Delete action and confirm. Deletion cannot be undone in the app; the app will alert you if its associated media file could not be removed.

Previews and captured images

A link preview may show a site image or icon supplied by a website. It is not a screenshot. A screenshot is stored only when you select an actual image for Save Snapshot or Save Both, or explicitly choose Save Visible Area in the Safari extension. Safari visible-area capture does not save an entire webpage.

If something does not appear

  • After sharing, open LivingMemory and allow a pending capture to import. If the free saving limit has been reached, the app may keep a new capture pending until you free a slot or obtain Pro access.
  • Check the original link or media file if a preview, video, extracted text, or transcription is unavailable. Results depend on the source, format, language, network connection, and Apple system capabilities.
  • If a subscription does not appear, open the Upgrade screen and choose Restore Purchases. The app verifies entitlements through StoreKit.

Getting help

For help, email aomlivingmemory@gmail.com.

When contacting support, it can help to include your device model, iOS version, LivingMemory version, the action you took, and the exact error shown. Share private saved content only if you choose to do so.
